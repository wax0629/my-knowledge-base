# 知识库同步方案

## 摘要

对于只使用电脑的个人知识库，本地 Markdown 文件夹配合 GitHub 私有仓库即可完成跨电脑同步和版本备份。免费 Obsidian 可以作为阅读和编辑界面，但它本身不等于同步服务。

## 核心内容

- 本地文件夹是知识库的数据源。
- GitHub 私有仓库保存远程副本和提交历史。
- 每台电脑先克隆仓库，开始工作前执行 `git pull --rebase`，完成一组逻辑变更后提交并 `git push`。
- GitHub 适合版本管理和备份，不是实时同步盘。
- Obsidian Sync 的优势是后台自动同步、离线使用和版本恢复，但它是付费服务。
- 不建议让 Git、iCloud/Dropbox 和 Obsidian Sync 同时管理同一个 Vault。

## 与已有知识的关系

本知识库当前采用“免费 Obsidian + 本地 Markdown + GitHub 私有仓库”的方案。后续如果手动同步成本过高，再评估 Obsidian Sync。

## 我的理解

只用电脑时，手动 Git 同步的复杂度可接受，且能保留清晰的版本历史。同步纪律比选择哪一个编辑器更重要。
